# RICK Memory — 2026-09-02

## Security boundary increment

- Michael Smith approved completion of the remaining product-readiness program,
  with security first, scoring accuracy second, and UI/UX third.
- The first bounded security increment implements mandatory bearer authentication
  for API routes except the independently HMAC-authenticated GitHub webhook.
- Non-loopback operation fails closed without `CODESONAR_API_TOKEN`; tokenless
  use is limited to explicit loopback development mode.
- CORS is an exact environment-configured allowlist with local-only defaults.
- Caller-controlled scan, hotspot, history/drift, and remediation repository
  paths are contained beneath `CODESONAR_SCAN_ROOT` by default. The unsafe legacy
  path mode is an explicit development-only escape hatch.
- Regression tests cover authentication, startup configuration, hostile/configured
  origins, path escape rejection, and preservation of webhook HMAC behavior.

## Scoring authority increment

- Analyzer runs now return explicit completion records. Any analyzer failure
  prevents an authoritative score/grade instead of being treated as no findings.
- Scoring version `1.0` is exposed by scan APIs and persisted in history;
  existing unversioned records load as `legacy-unversioned`.
- Focused regression coverage addresses failure gating, complete scans, version
  round trips, legacy loading, and unchanged-input determinism.
- Added an empty, versioned benchmark scaffold for frozen findings and blinded
  expert labels; no repositories or labels were invented and calibration did
  not change.
