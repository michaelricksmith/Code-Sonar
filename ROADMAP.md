# Roadmap

Where Code Sonar is headed. This page is updated as plans firm up, so anyone checking in can see what is on the horizon. No dates are promised. Feedback from early users decides what moves up the list.

## Where Code Sonar is today

- A code health score from 300 to 850, with an A to F grade, for any GitHub repository
- Eight automated checks covering oversized files and functions, complexity, nesting depth, leftover TODO and HACK markers, exposed secrets, testing gaps, and dead code
- Findings in plain English, each with the file, the line, the severity, and an estimated fix time
- Fix prompts built from the real finding, ready to paste into your AI assistant
- Ask Sonar: ask questions about your scan and get answers grounded in your actual results
- Score drift tracking across scans: what is new, what is fixed, and what is getting worse

## Next phase: Code Sonar on the go

The next phase takes Code Sonar mobile, so you can check on your code wherever you are.

- An installable web app: add Code Sonar to your phone's home screen, no app store needed
- Results designed for small screens: your score, your findings, and your drift at a glance
- Offline access to your most recent scan results
- One tap to copy a fix prompt and take it straight to your AI assistant
- A smoother first scan: connect a repo and see your score faster

## After that

- Push notifications when a scan finishes, so a long scan never keeps you waiting at your desk
- codesonar.tech becomes the home of the app
- Free scans open up beyond the current invite rollout

## The principle behind the order

Code Sonar exists because AI now writes code faster than anyone can review it. The roadmap follows that problem: first make the health check easy to reach from anywhere, then make it impossible to miss when your score moves.

Want to influence what ships next? Open an issue with what you are running into. Early feedback genuinely reorders this list.
